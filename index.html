WORD DOCUMENT GUIDE

Document formatting instructions

Use this quick guide to keep your document consistent, readable, and ready to submit.

1. Set the document font

Select all text with Ctrl + A, then choose Times New Roman, 12 pt from Home > Font. Use bold only where the heading levels below require it.

To make this the default for future documents, open the Font dialog, set Times New Roman at 12 pt, choose Set As Default, then apply it to documents based on the Normal template.

2. Use a clear heading hierarchy

Main heading 16 pt

Times New Roman, bold, left-aligned.

1. INTRODUCTION

Subheading 14 pt

Times New Roman, bold, left-aligned.

1.1 Background of the Study

Minor heading 12 pt

Times New Roman, bold, left-aligned.

Objectives of the Study

3. Set body text and page layout

  • Body text: Times New Roman, 12 pt, regular weight. Select the body paragraphs and press Ctrl + J to justify them.
  • Keep headings left-aligned: select each heading and press Ctrl + L.
  • Paper: Layout > Size > A4 (21 × 29.7 cm).
  • Margins: Layout > Margins > Normal for 1 inch (2.54 cm) on all four sides. Use Custom Margins to check each value if needed.

4. Add and present figures

  • Use clear, properly sized, relevant images, diagrams, flowcharts, or illustrations.
  • Introduce every figure in the text, explain its importance, and mention its number before placing it.
  • Number figures by module (for example, Figure 1.1, Figure 1.2, Figure 2.1).
  • Put a descriptive caption directly below each figure, with minimal space between text, image, and caption.
  • Keep each figure close to the explanation it supports.

Figure 1.1 illustrates the recommended order for presenting a figure. Introducing and numbering it first helps readers understand why the visual matters before they see it.
